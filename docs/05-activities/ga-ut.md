## @ga-ut/store
### 내용
- React에서 사용할 수 있는 전역 상태 라이브러리
- 단순한 문법과 보일러플레이트 제거를 통해 개발자 경험 개선
- 상태 선택 구독과 개발자 경험 개선을 실험하며 설계, 개발
- 타입 안정성 및 자동 렌더링 최적화 제공
- 다양한 상황에 대한 테스트 코드 제공
