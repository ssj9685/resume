# EVAR에서의 나

EVAR은 작은 팀에서 초기 서비스를 만들며 제품의 처음과 운영을 동시에 경험한 시간입니다. 전기차 충전기 앱, 관리자, 지도 기반 운영 화면, 출시 자동화까지 여러 일을 가까이에서 봐야 했습니다.

## 초기 서비스의 속도와 불완전함

요구사항이 항상 완성된 형태로 주어지지는 않았습니다. 실제 사용자 흐름을 보고 화면 구조와 기능 범위를 구체화해야 했고, 앱과 관리자와 운영 환경을 함께 맞춰야 했습니다.

이 경험은 제가 완벽한 기획을 기다리기보다 먼저 기준안을 만들고, 사용 가능한 형태로 좁혀 가는 방식을 익히는 계기가 됐습니다.

## 앱과 운영 화면을 함께 본 경험

충전 시작, 결제, 카드 등록, 실시간 상태 반영 같은 기능은 사용자가 직접 만지는 흐름이면서 운영자가 뒤에서 확인해야 하는 흐름이기도 했습니다.

사용자 앱과 관리자 화면을 같이 보면서, 사용자 경험과 운영 경험이 분리되어 있지 않다는 것을 배웠습니다. 한쪽이 불안하면 다른 쪽의 부담이 커졌습니다.

## 소수 인원 환경에서 배운 것

작은 팀에서는 역할 경계가 넓어집니다. 플러터 앱, 넥스트 기반 관리자, 지도, 배포 자동화, 웹뷰와 네이티브 연동까지 필요한 일을 직접 확인해야 했습니다.

이 경험은 제가 낯선 영역을 피하지 않고, 필요한 만큼 파고들어 서비스가 굴러가게 만드는 태도를 갖게 했습니다.
