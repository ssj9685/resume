# 충전기 관리자에서 본 상태 기반 운영

충전기 관리자는 충전기 위치, 상태, 원격 제어, 로그를 보는 화면이었습니다. 지도 위에 장비가 놓이고, 각 장비의 상태가 운영 판단의 기준이 되는 구조였습니다.

## 상태를 한눈에 보는 일

운영 화면에서 중요한 것은 많은 기능보다 현재 상태를 정확히 보는 일입니다. 어디에 충전기가 있고, 어떤 상태이며, 원격으로 무엇을 할 수 있는지 빠르게 이해되어야 합니다.

이 경험은 제가 관리자 화면을 볼 때 "데이터가 있다"보다 "운영자가 지금 무엇을 판단할 수 있는가"를 먼저 보게 만들었습니다.

## 초기 환경을 정리하는 일

프론트엔드 개발 환경이 충분히 갖춰지지 않은 상태에서 기술 스택을 바꾸고, 운영 환경과 개발 환경을 나누고, 배포 흐름을 만들었습니다.

이때 배운 것은 초기 서비스에서는 기능 개발과 기반 정리가 분리되지 않는다는 점입니다. 팀이 계속 제품을 바꿀 수 있으려면 화면뿐 아니라 개발과 배포의 기본 구조도 함께 잡혀야 합니다.
