# 메디큐브톡과 포인트샵에서 본 사용자 행동

메디큐브톡과 포인트샵은 사용자가 글을 쓰고, 포인트를 얻고, 상품을 보고, 구매로 이어지는 흐름을 다룬 경험입니다. 겉으로는 커뮤니티와 커머스 기능이지만, 실제로는 사용자 행동과 보상 정합성이 강하게 연결되어 있었습니다.

## 포인트는 단순한 숫자가 아니다

포인트 사용과 지급은 사용자가 민감하게 느끼는 영역입니다. 화면 반응이 빨라도 실제 정합성이 맞지 않으면 신뢰가 깨집니다. 반대로 정합성만 보고 사용자를 오래 기다리게 해도 경험이 나빠집니다.

중복 지급, 락, 롤백, 낙관적 업데이트를 다루며 사용자 경험과 데이터 정합성 사이의 균형을 계속 보게 됐습니다.

## 다국가 서비스에서 흔들림을 줄이는 일

다국가 서비스에서는 번역만 맞으면 끝나지 않았습니다. 언어 상태, 서버 렌더링, 쿠키, 이미지, 캐시, 앱 재진입, 레이아웃 흔들림이 함께 맞아야 했습니다.

작은 깜빡임이나 느린 상세 페이지도 사용자에게는 서비스가 불안정하다는 신호가 될 수 있습니다. 이 경험은 제가 성능과 안정성을 사용자 경험의 일부로 보게 만든 계기입니다.

## 이 경험이 남긴 것

사용자 행동은 화면 안에서만 완성되지 않습니다. 보상 정책, 서버 응답, 캐시, 앱 진입 흐름, 운영 데이터가 함께 만들어냅니다.

저는 이후에도 사용자 경험을 볼 때 눈에 보이는 UI와 보이지 않는 정합성을 같이 보려 합니다.
